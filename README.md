# Elephant Room Site Workspace

## Project Structure
- `html/`: Latest HTML files for the website
- `content/images/`: Local image storage (supplementary to GitHub-hosted images)
- `code_injection/`: Ghost CMS code injection files

## Image Hosting Strategy
- Primary image hosting: GitHub repository (M0nkeyFl0wer/elephant-room-site)
- Existing GitHub image links will remain unchanged
- Local `content/images/` for any new or additional images

## Workspace Notes
- HTML files represent the most recent version of the site
- Existing image URLs point to GitHub raw content
- Designed for seamless migration to Ghost CMS

## Workflow
1. Develop and refine HTML files in this workspace
2. Maintain existing image references
3. Prepare for Ghost CMS migration

## Key Considerations
- Preserve inline styles for Ghost compatibility
- Maintain consistent color palette and typography
- Ensure responsive design across all pages
